# bimover — Releases

Öffentliches Release-Hosting für die **bimover-App** (Support- und
Fernwartungs-Client). Kein Quellcode — nur Downloads und der
Sparkle-Update-Feed.

- **Download (neueste Version):** siehe [Releases](../../releases/latest) —
  `bimover-<version>.zip`
- **Update-Feed (Sparkle 2):** [`appcast.xml`](appcast.xml), ausgeliefert über
  `https://updates.bimover.ch/support/appcast.xml`
- **Webseite:** <https://bimover.ch/support>

Die App aktualisiert sich nach der Installation selbst (Sparkle 2,
EdDSA-signiert, notarisiert).
